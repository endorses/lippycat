# v0.11 Phase 10 validation evidence

**Date:** 2026-09-02

**Host:** Linux/amd64, Intel Core i9-13900HX, Go 1.26.3. Detector timing used
`GOMAXPROCS=1`; all commands used `GOCACHE=/tmp/lippycat-go-cache`.

This pre-production qualification extends the before/after data in
`docs/benchmarks/v0.11-phase1-baseline.md`. The workloads below exercise the
production data structures and packet-writer paths without a privileged live
interface. They do not replace the production soaks retained in the plan.

## Results

- RTP lookup ran for about two minutes across 10, 1,000, and 5,000 active calls.
  Destination hits were 136-154 ns/op, source hits 149-162 ns/op, and misses
  115-127 ns/op. Every case remained at two allocations; byte differences
  (32-40 B/op) are endpoint string width, not registry cardinality. This replaces
  the baseline's linear hit cost and active-call slice allocation. Functional
  lookup and race tests passed.
- Sustained detector insertion at caps of 1,000, 10,000, and 100,000 kept
  ordinary p95 insert latency below 1 us in this run. Isolated 100,000-entry
  eviction batches took 18.23 ms for `FlowTracker` and 11.37 ms for
  `DetectionCache`, below the documented 100 ms packet-buffer budget. Repeated
  pressure warnings and telemetry demonstrated recurring pressure episodes;
  cardinality remained hard-capped. The controlled workload has no packet-buffer
  producer, so application drops are zero by construction rather than a live-NIC
  loss claim.
- The per-call lifecycle stress run performed 1.79 million concurrent
  manager-owned writes at 668 ns/op. Tombstone admission stayed allocation-free
  at 10, 1,000, and 100,000 entries (52-57 ns/op), and pruning 100,000 expired
  entries took 3.59 ms. Lifecycle integration tests covered idle closure,
  endpoint reuse, late packets during finalization, rotation, collisions, and
  re-entrant hooks; finalized bytes/hashes remained unchanged and completion
  callbacks fired once where policy permits.
- CPU work is now in constant-time endpoint/map operations on ordinary hits;
  allocation counts do not grow with cardinality. Reusable eviction scratch and
  allocation-free tombstone admission bound GC pressure. Race tests and the
  contention benchmark found no lifecycle races; the 100,000-entry contention
  run reported p99 ordinary events of 1.33 us (`FlowTracker`) and 460 ns
  (`DetectionCache`). No unbounded mutex hold remains on periodic expiry.

Production must still record sustained packet rate, CPU, RSS, queue occupancy,
application/libpcap drops, recurring detector telemetry, finalized hashes, hook
counts, and writer/tombstone occupancy during the three operational soaks. This
document intentionally makes no live-NIC or long-duration resource claim.

go test -tags processor ./cmd/process ./internal/pkg/processor/...

All targeted unit, race, tagged-role, vet, and complete test commands passed.
Tap/processor tests were run with loopback access because their integration tests
open local sockets.
